# BMS差分収集ツール

**難易度表から、足りないBMS楽曲・差分を探して導入する。**  
beatoraja向けに、譜面の所持判定・自動ダウンロード・適切な楽曲フォルダへの配置を支援するWindows用ツールです。

「元曲はあるけれど差分がない」「差分だけ取得できて元曲がない」といった状態を確認し、不足するデータの取得・補完・整理を進められます。

## ツールの概要

難易度表に掲載された楽曲・差分と、登録したBMS曲フォルダの所持譜面を照合し、未所持のデータを集めるためのツールです。元曲（音源などを含む楽曲本体）と差分（追加の譜面）を区別し、別々の配布元から取得したデータや手動で入手したファイルの統合も支援します。

**難易度表を読み込む → 所持状況を確認 → 不足分を取得 → 配置・確認** が基本の流れです。すべての配布元を自動処理できるわけではないため、手動ダウンロードや配置待ちの再試行も組み合わせて使用します。

## 主な機能

| 機能 | できること |
| --- | --- |
| BMS楽曲・差分の自動取得 | 難易度表の未所持譜面について、必要な元曲・差分の取得と配置を支援します。 |
| 難易度表の検索・読み込み | 難易度表のWeb検索、URL追加、表のページ表示、レベルによる絞り込みに対応します。beatorajaからBMSフォルダと難易度表URLを取り込むこともできます。 |
| 元曲・差分の所持判定 | 保存済みの所持譜面索引を利用し、譜面ハッシュと使用音源を確認して、所持・配置・完了を判定します。 |
| 複数サービスでの取得先検索 | MD5を使ったGingerRush・BMS SEARCH・LR2IR Archiveへの問い合わせ、難易度表URLや作者の配布ページなどからの探索に対応。取得に失敗した場合は別の候補URL・サービスを試します。 |
| 公開共有リンクへの対応 | Google Drive・Dropbox・公開アップローダーなどの配布リンクからの取得に対応します。公開範囲や配布形式によっては手動操作が必要です。 |
| 元曲・差分の自動補完と統合 | 別々に取得した元曲・差分や、取得済みの途中データを照合して統合します。v3.3.0では差分取得後に不足している元曲を並列取得します。 |
| ドラッグ＆ドロップによる手動導入 | 手動で入手した圧縮ファイル・譜面・フォルダをまとめて取り込み、元曲との照合・配置を支援します。 |
| 重複ファイルの整理・統合 | 「候補を一括表示」で実ファイルを比較し、選択コピー・一括コピー・削除前の未保存ファイル確認ができます。同一パックの重複取得・配置も抑制します。 |
| 配置の診断・修復 | 「配置を修復」で誤配置や音源不足の疑いを診断し、配置修復・入手先案内・元曲の自動ダウンロードを支援します。診断結果の保存・再表示・検索の続行にも対応します。 |
| ダウンロードの設定・履歴・管理 | 「取得設定」で利用サービス・優先順位・同時ダウンロード数・待ち時間・一時保存先を変更できます。取得元サービス別の結果・履歴・統計、ログ、失敗・保留状態を確認できます。 |

自動補完・所持判定には、[報告されている問題](#github-issuesに報告されている問題)もあります。特に追加音源を含む差分は、導入後のファイル構成を確認してください。

## 初めての導入

### 1. ダウンロードして展開する

1. 冒頭のReleasesリンクから、**v3.3.5の配布用ZIP**を選んでダウンロードします。
2. ZIPの中身を任意のフォルダへすべて展開します。
3. 展開したフォルダの **`BeatorajaMissingChartFetcher.exe`** を起動します。

Windows／.NET Framework 4.8を使用するアプリです。同梱の `tools` や `data` も含め、展開した構成を保ってください。詳しい説明は配布ZIP内の `README.txt` にあります。

### 2. BMS曲フォルダを登録し、索引を作る

1. 初回画面の「DLするフォルダを選択」で、既存のBMS曲フォルダまたは新しい曲の保存先を登録します。まだBMSを持っていない場合は、空の専用フォルダを選んでください。
2. beatorajaの設定を利用したい場合は、任意で「beatorajaから読込」を使い、BMSフォルダと難易度表URLを取り込みます。
3. 初回は「索引を更新」を実行し、所持譜面索引を作成します。登録時に索引作成を案内された場合は、その案内から進められます。

**曲フォルダ未登録の間は、ダウンロード・手動取り込みを開始できません。登録後はボタン名が「管理」に変わります。**

索引は、登録フォルダ内のどの譜面を所持しているか照合するための情報です。フォルダを変更したときや、別の方法で譜面を追加したときも更新してください。整理・修復を行う前には、大切なBMSデータのバックアップをおすすめします。

### 索引なしで試す場合・後から索引を作る場合

フォルダ登録後、索引作成の案内で「いいえ」を選ぶと、お試し利用できます。取得した本体と差分の導入はできますが、以前から持っている曲を十分に照合できず、**重複取得・重複配置や、差分が配置待ちになる場合があります。** 継続して使う前に索引を作成してください。

後から作るには、画面上部の **「再作成」** を押します。登録した全BMS曲フォルダとサブフォルダを確認し、索引を最初から作ります。曲・譜面ファイル自体は変更しません。索引がない場合は「索引を更新」でも全体を作成できます。

### 3. 難易度表を読み込む

1. 使用する難易度表を選びます。必要に応じてWeb検索やURL追加で登録します。
2. 「表を読み込む」を押します。
3. 対象レベルを選び、「選択レベルを検索」を押して所持状況を確認します。

元曲と差分のどちらが不足しているかを確認してから取得に進みます。

### 4. 不足している譜面を取得する

1. 必要に応じて「取得設定」で利用サービスや同時ダウンロード数などを調整します。
2. 「未所持をまとめて取得」を押します。
3. 一覧の進捗・取得結果を確認します。取得できなかったものや、片方だけ取得できたものは、手動導入や配置待ちの再試行で補完します。
4. 導入後は必要に応じてツールの索引を更新し、beatoraja側でも曲フォルダを再読み込みします。

「導入済み」は今回の起動中の表示で、再起動後は「所持済み」へ変わります。取得済みの本体候補は、差分との対応が確認できるまで導入済みにはなりません。

## 更新方法

1. **アプリを終了します。**
2. 最新版ZIPをダウンロードし、展開します。
3. 展開した中身を、以前と同じアプリフォルダへ上書きします。
4. `BeatorajaMissingChartFetcher.exe` を起動します。

2026-10-30に、一覧画面の応答停止を修正したv3.3.5へ差し替えました。既にv3.3.5を利用している場合も、上のZIPをダウンロードし直して上書きしてください。

設定・索引・途中状態は引き継げます。設定・受信箱・ログなどは、アプリの配置先とは別の **`ドキュメント\BeatorajaMissingChartFetcherData`** に保存されます。

v3.2.0以降は音源確認を見直しているため、以前の「導入済み」が未完了になる場合があります。その場合は「配置を修復」で状況を確認してください。

## 手動導入と整理

### 自動取得できなかった場合

配布ページを開き、配布元の案内に従って手動でダウンロードします。ログイン・人間確認・合言葉などが必要な配布先や、リンク切れは自動処理できない場合があります。

取得したファイルは、**青いドラッグ＆ドロップ欄または一覧**へドロップします。ZIP・7z・RAR、BMS・BME・BML・PMS・BMSON、フォルダの取り込みに対応しています。元曲と差分を別々に入手した場合も、後から不足側を取り込んで照合・配置できます。元の手動ダウンロードファイルは移動・削除しません。

### 片方だけ取得できた場合・配置待ちの場合

- 「取得済み差分を開く」「取得済み楽曲を開く」で保存済みデータを確認します。
- 「保留場所一覧」で保留中のファイルを確認します。
- 不足する元曲・差分を入手した後、「配置待ち再試行」で再照合します。
- 詳細を調べる場合は「ログを見る」を利用します。

### 重複を整理する場合

「候補を一括表示」で実ファイルを比較し、残すフォルダとコピー対象を確認して統合します。手動コピーでは同名の別内容を上書きせず、元フォルダの削除にはごみ箱への移動を使用します。

手動統合後は、**ツールの索引更新とbeatoraja側の曲フォルダ再読み込み**を行ってください。

### 配置を修復する場合

「配置を修復」で診断し、ファイル名・所属難易度表・レベルと診断結果を確認します。「正しい場所へコピー」は元譜面を残し、「元譜面をごみ箱へ」は導入先を再確認して元譜面を送ります。本体が見つからない場合は入手先案内や「元曲をDL」を利用できます。

修復で解決しない場合は、追加音源の不足や元曲の誤判定について、下記のIssuesも確認してください。

## 既知の問題・注意事項

### 自動取得の制限

- 配布方法やサイトの仕様変更により、自動取得できない楽曲・差分があります。
- ログイン・人間確認・合言葉・ブラウザー操作が必要な場合は、手動で取得してください。Google DriveやDropboxも、すべての共有形式・権限設定に対応するわけではありません。
- パスワード付き・破損・分割不足の書庫は自動展開できません。
- 配布元の利用規約・ルールに従って利用してください。本ツールが楽曲・差分そのものを再配布するものではありません。

### セキュリティソフトの検出について

旧版には、一部のセキュリティソフトでウイルスやTrojan等として誤検知される問題がありました。v2.0以降は軽減のための見直しを行っていますが、配布アプリにはAuthenticodeコード署名がなく、今後も検出される可能性があります。**「完全に安全」「ウイルス検知なし」を保証するものではありません。**

警告が出た場合は検出内容と配布元を確認し、実行するかを慎重に判断してください。配布ZIP内の `SHA256SUMS.txt` や `SECURITY-AUDIT.md` も参照できます。ハッシュの照合はファイルの一致を確認するもので、安全性そのものの証明ではありません。

## 強制終了を調べる場合

通常は `BeatorajaMissingChartFetcher.exe` を起動します。強制終了を調べるときはアプリを閉じ、同梱の **`BMS-CrashWatch.exe`** から起動してください。終了コードや使用メモリなどを記録します。使い方は同梱の「診断ツールの使い方.txt」を参照してください。

診断ログは `ドキュメント\BeatorajaMissingChartFetcherData\logs\diagnostics` に保存されます。ログの自動送信はありません。診断ログと、問題発生時の `latest.log` の末尾100～200行を、個人のパスなどを伏せて共有してください。

[#5で報告されている一括取得中の強制終了](https://github.com/aki0311-commits/BMS-/issues/5)は調査中です。v3.3.5の修正・診断ツールの同梱をもって解決済みとはしていません。

## 不具合の報告

[GitHub Issues](https://github.com/aki0311-commits/BMS-/issues)で既存の報告を確認したうえで、次の情報を添えて報告してください。

- 使用バージョン、対象の楽曲・差分名

- 元曲・差分の所持状況、実行した操作、再現手順
- 期待した結果と実際の結果、エラーメッセージ
- 必要に応じて関連ログや画面の画像（個人情報などは除いてください）

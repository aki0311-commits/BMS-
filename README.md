# BMS-
# BMS差分収集ツール

beatoraja向けの **BMS楽曲・差分の収集、整理、導入を支援するツール** です。

難易度表などから欲しい譜面を探した際に、

「楽曲はあるけど差分がない」  
「差分は見つかったけど本体楽曲がない」  
「ダウンロードしたけど、どこに入れればいいか分からない」

といった作業をできるだけ自動化することを目的にしています。

---

## 主な機能

- BMS楽曲・差分の自動取得
- 所持済み楽曲の判定
- 楽曲／差分の自動振り分け
- ダウンロードしたファイルの自動配置
- 楽曲のみ取得できた場合、不足している差分の取得を支援
- 差分のみ取得できた場合、不足している楽曲の取得を支援
- 自動取得できなかった譜面の手動導入支援
- 難易度表を利用した譜面管理
- 取得に失敗した譜面・保留中の譜面の管理

「Assets」にある

`BeatorajaMissingChartFetcher-share.zip`

をダウンロードしてください。

※「Source code (zip)」ではなく、上記のファイルを使用してください。

---

## 基本的な使い方

### 1. ダウンロード

Releasesから最新版のZIPファイルをダウンロードします。

### 2. ZIPを展開

ダウンロードしたZIPファイルを任意の場所に展開してください。

### 3. ツールを起動

展開したフォルダ内からツールを起動します。

### 4. beatorajaの環境を設定

初回起動時に、使用しているbeatoraja／BMS楽曲フォルダなど必要な場所を設定します。

### 5. 譜面を探す

難易度表などから導入したい譜面を選択します。

ツールが現在のBMS環境を確認し、

- 楽曲・差分ともに所持済み
- 楽曲のみ所持
- 差分のみ所持
- 両方未所持

などを判定し、必要なファイルの取得・配置を支援します。

---

## 自動取得できなかった場合

BMSの配布方法はサイトごとに異なるため、すべての楽曲・差分を自動取得できるわけではありません。

自動取得に失敗した場合でも、配布ページを開いて手動でダウンロードし、その後ツールを使って適切な場所へ配置できるようにしています。

「自動取得できない = 導入できない」ではなく、可能な範囲まで自動化し、残りを手動で補完する設計です。

---

## 難易度表について

難易度表を利用して譜面を管理できます。

所持状況を確認しながら、未所持の楽曲・差分を効率よく集める用途を想定しています。

---

## 注意事項

- 自動取得できない楽曲・差分があります。
- 配布元サイトの仕様変更により、一部機能が正常に動作しなくなる場合があります。
- 配布元の利用規約・ルールに従って使用してください。
- 楽曲・差分そのものを本ツールが再配布するものではありません。
- 本ツールは個人制作の非公式ツールです。
- beatorajaおよび各難易度表・配布サイトとは直接関係ありません。

---

## 不具合について

正常に取得できない楽曲・差分や、不具合がある場合はGitHubの **Issues** から報告してください。

可能であれば、

- 対象の楽曲／差分
- 使用した難易度表
- 発生した症状
- エラーメッセージ
- 再現手順

などを書いていただけると原因を確認しやすくなります。
